# Greenery Lab 7

Учебный проект — интернет-магазин мебели на React + Redux.

## Технологии

- React
- Redux Toolkit
- React Router
- React-Bootstrap
- i18next (русский / английский)

## Установка и запуск

cd client
npm install
npm start

## Функционал

- Каталог товаров с поиском, фильтрацией и сортировкой
- Корзина покупок
- Избранное
- Отзывы
- Админ-панель (admin@example.com / admin123)
- Переключение языка (RU / EN)
- Тёмная и светлая темы
